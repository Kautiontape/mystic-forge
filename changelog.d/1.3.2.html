The board paints first and fills in after

A board now sends its title, theme and layout the instant you ask for it, then the cards arrive as the prices are read — so the page is on screen in a blink even when the server is cold, and a slow board no longer holds up Claude's tool calls while it renders. The reading itself got much cheaper too: each card's price history is fetched once instead of three times, the newest price at each shop is found by lookup rather than by reading every price on record, and the index every board reads from now carries the price itself, so a card's history is one run of pages rather than a scatter of them. Also fixes a mistake in 1.3.1: the index it added to answer the “prices through” line could tempt the database into reading every price at a shop when the board was set to that single market. That line is now answered from the board's own cards, and the index is gone.

A board now paints its title and layout instantly and fills in the cards as prices are read — on screen in a blink even from a cold server. Reading got cheaper too: history fetched once per card, newest shop prices by lookup, and a covering index so a card's history is one run of pages. Also fixes 1.3.1's single-market slowdown.
