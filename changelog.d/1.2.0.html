Price history that outlives MTGJSON's window

A watchlist used to show only what MTGJSON still had — a rolling ~90 days — and adding a card meant waiting while the server streamed a 1.4 GB price file end to end just to find that card's rows. Prices now land in a store the server keeps itself: 120 days at daily resolution, and weekly averages kept indefinitely beyond that. A list you have held for a year has a year of history rather than a quarter, and it keeps accumulating. Adding a card reads that store by index instead of scanning the file, so history shows up while the page is still loading. Mana Pool also joins TCGplayer, Card Kingdom, and Cardmarket as a fourth price source. The store builds itself once after this release and takes a while to fill; until it does, every watchlist keeps working exactly as it did before.
